#80 曾要求正文与管理台共用 900px 外层 / 860px 文本列，该部分已被用户后来选定的 B 紧凑工作台规格替代。#85 明确保留 68ch 并居中，避免中文长文随宽主列拉长；代价是桌面正文两侧留白。#86 又明确管理外壳 1140px。故本次没有执行旧票的 900px 回退，也没有通过删掉 68ch 断言来让旧票看似完成。

同理，#77 的 `/account/password` 与页头独立改密链接被 #87 的 `/account` 与用户菜单覆盖；所需的改密校验、CSRF、PRG 和会话语义仍须验证。已删除的 Docker 制品与 `check:docker` 不再属于 #81 的有效门禁，部署真源是 [部署环境](deploy-environment.md)。

实现、回归、视觉证据和 GitHub 处理状态见 [剩余 issue 收口报告](remaining-issues-closeout.md)。
