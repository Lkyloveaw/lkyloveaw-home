## 独立审查与修复

独立只读审查提出 Critical 0、Important 3、Minor 2；全部五项已处理，并用失败用例证明问题存在后修复：

1. **删除后旧探测写回**：真实本机 HTTP 门闩复现清空、清空后复用 id、无历史物理删除三种场景，原实现 0/3。目标模块在物理删除成功后推进进程内代际，轮次只落仍有效的结果；修复后 3/3，正常对照目标仍写入，普通停用语义不变。接入 `check:backup`。
2. **真实卡片尺寸不匹配**：首屏 232×54，但刷新使用 520×110。刷新改读实际 SVG viewBox；panel 用实际尺寸验证所有点未越界。
3. **值域只记录未参与画线**：SSR 与客户端现在把实际 domain 用于 y 映射；可用率固定 0–100，延迟只扩不缩，超界夹紧。用实际 path 中同一老点的 y 验证尖峰离场不跳，替换原来的恒等检查。
4. **首次空数据无横轴**：轴也保留稳定三槽骨架，后续数据可原地更新。
5. **回到空态仍读出旧数值**：清除平均/峰值文字，恢复 SVG 的数据不足标签；覆盖层不再是唯一的空态表达。

第 4/5 项虽被审查员标为 Minor，本轮按功能缺陷处理：首次数据缺时间依据、辅助技术读出过期数值会误导使用者，不属于单纯样式偏好。对应 chart/panel 断言先出现 3 项 / 2 项失败，修复后全部通过。无未处理的本轮审查发现。
