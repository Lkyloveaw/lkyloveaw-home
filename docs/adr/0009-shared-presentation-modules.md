# 0009：Node 与浏览器直接共用呈现计算模块

2026-10-24，采用。状态展示、图表几何和 HTML 转义改为 public/ 下的原生 ES module，服务端直接导入同一文件，浏览器从 status.js 的 module 入口导入；相邻的 .d.ts 提供服务端类型接口。这样删除两份实现和“改一边必须改另一边”的约束，也不必为只读页面增加打包、复制产物或第三方图表依赖。SSR、禁用 JS 时可读及公开状态投影保持原有契约，延续 ADR 0001、0003、0006 和 0008。

新增客户端依赖要逐一进入 auth.ts 的精确资源白名单，声明文件不匿名放行。几何和展示模块不读数据库、不操作 DOM；页面模板和浏览器更新各自调用。测试里使用已有 esbuild 在内存解析浏览器模块依赖图，不产生新的生产构建产物。

图片输入校验改用具名 MediaInputError，上传适配器统一读取、存储和失败分类；权限、CSRF、头像所有者和友联引用的保存仍属于路由。文件系统失败统一提示保存失败，友联在上传 await 后仍须确认条目存在。
