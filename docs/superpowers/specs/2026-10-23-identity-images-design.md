# 头像与网站徽标

用户于 2026-10-23 要求增加个人头像及导航栏左侧的网站徽标，此需求取代旧设计中不添加头像的边界。

- 个人设置的账户卡加入当前头像、上传/更换与恢复默认。头像用于胶囊、展开菜单和账户卡，仅当前用户可更改自己的头像。
- 管理台「站点设置」增加网站徽标卡片，供管理员上传/更换、预览或恢复默认。徽标显示在登录后页面导航栏左侧，不改变浏览器 favicon 或匿名媒体边界。
- 复用现有内容寻址媒体文件和 8 MiB / PNG、JPEG、WebP、GIF 校验，拒绝 SVG 和伪装文件。不增加依赖，不提供裁剪器。
- 增加一张小型身份图片引用表，分别保存各用户头像与站点徽标；图片引用随数据库保留，文件沿用现有媒体目录及部署备份规则。
- 上传和恢复默认均受登录、来源校验和 CSRF 保护。徽标还需管理员权限；恢复默认仅解除引用，不立即删除文件。
- 媒体清理必须保留当前头像、徽标、文章和修订的所有引用；读取失败仍拒绝删除。
- 页面使用短标签和必要的提交反馈，不添加说明性附注。默认头像保留姓名首字母，默认徽标保留原图标。

实现检查：头像用户隔离、徽标权限、CSRF/来源/类型/体积拒绝、替换与默认恢复、跨请求和重启持久化、媒体清理保留引用，以及窄屏/深色显示。
